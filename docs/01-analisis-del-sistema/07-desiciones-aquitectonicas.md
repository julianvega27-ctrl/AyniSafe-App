
# 07. Decisiones arquitectónicas

| ID | Decisión arquitectónica | Driver relacionado | Justificación | Resultado |
|---|---|---|---|---|
| ADR-001 | Monolito modular | DA01 – Escalabilidad; DA06 - Mantenibilidad | Organizar las funcionalidades en módulos con responsabilidades definidas dentro de un único backend, facilitando el mantenimiento y permitiendo escalar horizontalmente la aplicación cuando sea necesario. | Backend modular compuesto por Identidad, Reportes, Análisis, Operaciones, Alertas y Consultas. |
| ADR-002 | Clean Architecture | AD06 - Mantenibilidad; DA03 – Seguridad | Separar las reglas de negocio de los detalles tecnológicos, evitando que dependan directamente de frameworks, bases de datos o servicios externos. | Organización interna en Dominio, Aplicación, Presentación e Infraestructura, con dependencias orientadas hacia el núcleo del negocio. |
| ADR-003 | API REST compartida | DA04 – Comunicación entre clientes y backend | Establecer un mecanismo común de comunicación para la aplicación móvil y el panel web, centralizando las operaciones y reglas de negocio. | API REST desarrollada con Node.js, Express y TypeScript, que intercambia información mediante HTTPS y JSON. |
| ADR-004 | Procesamiento asíncrono | DA02 – Rendimiento; DA05 – Recuperación ante fallos | Evitar que las operaciones dependientes de servicios externos retrasen innecesariamente el registro de reportes y permitir el tratamiento de errores y reintentos. | Procesamiento desacoplado de tareas de análisis y notificaciones mediante trabajos en segundo plano y, cuando se requiera, una cola de mensajes como Amazon SQS. |
| ADR-005 | Estrategia de caché | DA01 – Escalabilidad; DA02 – Rendimiento | Reducir consultas repetitivas a la base de datos y mejorar el acceso a información consultada frecuentemente. | Incorporación prevista de Redis para almacenar temporalmente datos de consulta frecuente. |
| ADR-006 | Almacenamiento separado de evidencias | DA03 – Protección de datos; DA01 – Escalabilidad | Evitar almacenar archivos multimedia directamente en la base de datos relacional y facilitar su administración y control de acceso. | Amazon S3 para archivos de evidencia y PostgreSQL para sus referencias y metadatos. |
| ADR-007 | Despliegue en infraestructura cloud | DA01 – Escalabilidad; DA05 – Disponibilidad y recuperación | Contar con una infraestructura que permita ampliar capacidad, supervisar componentes y aplicar mecanismos de recuperación ante fallos. | Despliegue previsto en AWS, con servicios de cómputo, almacenamiento, base de datos y monitoreo. |
