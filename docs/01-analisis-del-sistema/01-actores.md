# 01. Actores del sistema

## Contexto
AyniSafe propone una aplicación móvil para ciudadanos de Ayacucho y un panel complementario de operaciones. Se distingue entre quienes interactúan con el sistema y los servicios externos.

| Actor | Necesidad |
|---|---|
| Ciudadano registrado | Reportar incidentes con ubicación autorizada y evidencia, consultar estado, mapa y alertas preventivas. |
| Operador autorizado | Revisar, validar, consolidar, derivar y actualizar incidentes; registrar actuaciones. |
| Administrador | Gestionar cuentas, roles, categorías, reglas de alertas y parámetros operativos. |
| Servicio de geolocalización del dispositivo | Proporcionar ubicación cuando el ciudadano concede permiso. |
| Servicio de notificaciones push | Entregar alertas y cambios de estado a dispositivos. |
| Servicio de IA | Sugerir categoría, prioridad orientativa y similitud entre reportes. |
