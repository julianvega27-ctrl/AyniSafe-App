# 02. Historias de usuario

| ID | Historia de usuario | Prioridad |
|---|---|---|
| HU01 | Como ciudadano, quiero crear una cuenta e iniciar sesión, para gestionar mis reportes de manera segura. | Alta |
| HU02 | Como ciudadano, quiero informar un incidente como invitado o con cuenta, para comunicar un hecho sin que el registro de cuenta sea obligatorio. | Alta |
| HU03 | Como ciudadano, quiero confirmar un punto del incidente por GPS autorizado o selección manual y adjuntar fotos opcionales, para aportar contexto; si soy invitado, informo un teléfono de contacto. | Alta |
| HU04 | Como ciudadano con cuenta, quiero consultar mi historial privado; como invitado, quiero consultar estado y resumen mediante código secreto, sin acceder a información ajena. | Alta |
| HU05 | Como ciudadano, quiero consultar incidentes publicables en un mapa dividido y filtrable por distritos metropolitanos, categoría y período, para tomar precauciones. | Alta |
| HU06 | Como ciudadano, quiero recibir alertas de incidentes cercanos relevantes, para evitar zonas de riesgo. | Alta |
| HU07 | Como operador, quiero revisar reportes recibidos y su información, para decidir si corresponde validarlos, consolidarlos o descartarlos. | Alta |
| HU08 | Como operador, quiero revisar la categoría y asignar una etiqueta de prioridad visible con color e icono, conservando orden de llegada y trazabilidad, para organizar la atención. | Media |
| HU09 | Como operador, quiero identificar reportes posiblemente relacionados, para evitar gestionar varias veces un mismo incidente. | Media |
| HU10 | Como operador, quiero derivar incidentes y registrar cambios de estado y actuaciones, para mantener su trazabilidad. | Alta |
| HU11 | Como administrador, quiero gestionar cuentas de los tres roles existentes, categorías y reglas de alerta, para mantener el funcionamiento del sistema. | Media |
| HU12 | Como operador, quiero consultar indicadores agregados por zona, categoría y franja horaria, para apoyar acciones preventivas. | Media |
| HU13 | Como ciudadano, quiero recibir cambios relevantes sobre un incidente que me afecta, para mantenerme informado. | Media |
| HU14 | Como administrador, quiero crear instituciones y sedes con su operador inicial, para organizar la atención institucional. | Alta |
| HU15 | Como administrador, quiero configurar distritos de cobertura y categorías atendidas por sede, para distribuir los reportes correctamente. | Alta |
| HU16 | Como operador, quiero recibir notificaciones y consultar avisos no leídos de reportes en mi ámbito, para revisar y atender los casos correspondientes. | Alta |
| HU17 | Como ciudadano, quiero consultar contactos de emergencia y abrir el marcador, para contactar a la entidad que corresponda. | Alta |
| HU18 | Como ciudadano, quiero editar mi perfil y consultar información de la app y sus desarrolladores, para gestionar mis datos y conocer el proyecto. | Media |
| HU19 | Como visitante, quiero una portada web informativa con acceso al inicio de sesión, para conocer la finalidad de AyniSafe. | Alta |
| HU20 | Como operador, quiero coordinar la institución principal y las entidades de apoyo según categoría y condiciones, para atender un mismo caso sin perder trazabilidad. | Alta |
| HU21 | Como administrador, quiero recibir avisos de mi ámbito de supervisión y de enrutamiento pendiente, para resolver faltas de cobertura o configuración. | Alta |
| HU22 | Como administrador, quiero mantener contactos de emergencia e información pública, para que los clientes muestren contenido vigente. | Media |
| HU23 | Como ciudadano, quiero completar una evaluación rápida cuando un reporte se dirija al SAMU, indicando heridos, cantidad y condiciones observadas de las personas afectadas, para aportar contexto sin tener que diagnosticar ni conocer todas las respuestas. | Alta |
| HU24 | Como operador del SAMU, quiero consultar la evaluación rápida y registrar aclaraciones con autor y fecha, para valorar el reporte conservando la información original del ciudadano. | Alta |
| HU25 | Como ciudadano, quiero elegir distritos, cercanía y categorías de alertas, y poder desactivarlas, para controlar la información que recibo. | Alta |
| HU26 | Como operador, quiero ver reportes en orden de llegada con etiquetas de prioridad, para reconocer su atención pendiente sin perder el orden de recepción. | Alta |
| HU27 | Como administrador, quiero supervisar conservación y eliminación por plazos sin acceder al contenido sanitario, para limitar almacenamiento y exposición de datos. | Media |
| HU28 | Como operador, quiero asumir un caso y ver quién es responsable en mi institución, para evitar actuaciones simultáneas sin coordinación y transferir la atención con trazabilidad. | Alta |

HU19 describe acceso público, no un cuarto rol. Criterios de aceptación y matriz de las 16 categorías: [alcance territorial e institucional](09-alcance-territorial-e-institucional.md).
