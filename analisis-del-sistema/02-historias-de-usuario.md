# 02. Historias de usuario

| ID | Historia de usuario | Prioridad |
|---|---|---|
| HU01 | Como ciudadano, quiero crear una cuenta e iniciar sesión, para gestionar mis reportes de manera segura. | Alta |
| HU02 | Como ciudadano, quiero registrar el tipo y la descripción de un incidente, para comunicar oportunamente un hecho observado. | Alta |
| HU03 | Como ciudadano, quiero adjuntar una ubicación con mi autorización y fotografías permitidas, para aportar contexto al reporte. | Alta |
| HU04 | Como ciudadano, quiero consultar el estado de mis reportes, para conocer su seguimiento. | Alta |
| HU05 | Como ciudadano, quiero consultar incidentes recientes en un mapa con información pública limitada, para tomar precauciones. | Alta |
| HU06 | Como ciudadano, quiero recibir alertas de incidentes cercanos relevantes, para evitar zonas de riesgo. | Alta |
| HU07 | Como operador, quiero revisar reportes recibidos y su información, para decidir si corresponde validarlos, consolidarlos o descartarlos. | Alta |
| HU08 | Como operador, quiero visualizar sugerencias de clasificación y prioridad generadas por IA, para apoyar mi revisión sin delegarle la decisión. | Media |
| HU09 | Como operador, quiero identificar reportes posiblemente relacionados, para evitar gestionar varias veces un mismo incidente. | Media |
| HU10 | Como operador, quiero derivar incidentes y registrar cambios de estado y actuaciones, para mantener su trazabilidad. | Alta |
| HU11 | Como administrador, quiero gestionar roles, categorías y reglas de alerta, para mantener el funcionamiento del sistema. | Media |
| HU12 | Como operador, quiero consultar indicadores agregados por zona, categoría y franja horaria, para apoyar acciones preventivas. | Media |
| HU13 | Como ciudadano, quiero recibir cambios relevantes sobre un incidente que me afecta, para mantenerme informado. | Media |
