# AyniSafe

**Cuidarnos es tarea de todos.**

## Descripción

AyniSafe es un proyecto de aplicación móvil orientado a fortalecer la seguridad ciudadana en la región de Ayacucho mediante el reporte georreferenciado de incidentes, la difusión de alertas preventivas y la participación colaborativa de la comunidad.

La plataforma permitirá a los ciudadanos reportar situaciones como robos, acoso, agresiones y otros incidentes, adjuntando información sobre su ubicación y evidencias. Asimismo, contará con un panel de gestión para operadores autorizados, quienes podrán verificar los reportes y dar seguimiento a los incidentes registrados.

El sistema incorporará inteligencia artificial para apoyar la clasificación, priorización y correlación de reportes, manteniendo la supervisión humana en las decisiones de atención.

## Objetivo

Desarrollar una plataforma móvil inteligente y escalable que facilite el reporte, la gestión y la prevención colaborativa de incidentes de seguridad ciudadana en Ayacucho, mediante información georreferenciada, alertas oportunas y mecanismos de análisis asistidos por inteligencia artificial.

## Metodología

El proyecto se desarrollará utilizando **Scrum**, mediante iteraciones que permitan planificar, implementar, evaluar y entregar incrementos funcionales del sistema.
